## 📌 Overview

**Java DSA Suite** is an academic reference repository containing clean, optimized implementations of fundamental Data Structures & Algorithms written in modern **Java**.

---

## ✨ Modules Included

- 📦 **Data Structures:** Custom Doubly LinkedList, Stack, Queue, Binary Search Tree (BST), Red-Black Tree, Max/Min Heap, Hash Table with Chaining.
- ⚡ **Sorting Algorithms:** QuickSort, MergeSort, HeapSort, CountingSort.
- 🕸️ **Graph Algorithms:** BFS, DFS, Dijkstra Shortest Path, Prim/Kruskal Minimum Spanning Tree.

---

## 🚀 Quick Start Guide

```bash
git clone https://github.com/RohithS03/java-dsa-suite.git
cd java-dsa-suite

javac -d bin src/com/dsa/*.java
java -cp bin com.dsa.Main
```
